## 🛠️ 오늘 작업 및 수정 내용 요약

### 1. 멀티 종목 백테스트 누락 문제 해결
- **현상**: 2개 이상의 종목을 선택하여 백테스트를 실행할 때, 일부 종목(예: SK하이닉스)의 거래 결과가 누락되는 현상 발생.
- **원인**: 초기 자본금이 100만 원으로 설정되어 있어, 비싼 주식(80만 원대)의 경우 종목당 가용 금액으로 1주도 살 수 없는(0주 주문) 물리적 한계 때문임을 규명.
- **조치**: 프론트엔드 기본 자본금을 **1억 원(100,000,000 KRW)**으로 상향 조정하여 일반적인 우량주 테스트가 원활하도록 수정했습니다.

### 2. UI/UX 고도화
- **종목명 표시**: `TradeHistoryTable`을 수정하여 거래 내역에서 종목 코드 대신 **한글 종목명(예: 삼성전자)**이 우선적으로 표시되도록 개선했습니다.
- **동적 로딩 메시지**: 분봉(Minute) 해상도 백테스트 시 데이터 수집 지연을 사용자가 인지할 수 있도록 실시간 상태 메시지 로직을 추가했습니다.
- **ReferenceError 수정**: `loadingMessages` 초기화 순서 문제로 발생하던 `ReferenceError`를 수정하여 런타임 안정성을 확보했습니다.

### 3. Docker 실행 환경 최적화 (macOS)
- **현상**: 백엔드 서버에서 `docker` 명령어를 찾지 못해 실행이 거부되는 현상.
- **조치**: `kis_backtest/lean/executor.py`를 수정하여 macOS 표준 경로(`/usr/local/bin/docker`)를 자동으로 탐색하고 `shutil.which`를 통해 동적으로 실행 파일을 찾도록 보완했습니다.
