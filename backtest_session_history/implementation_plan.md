# 분봉 백테스트 정밀 시각화 및 무결성 확보 통합 설계

이 문서는 한국투자증권(KIS) OpenAPI 기반의 분봉 백테스트 시스템을 정밀화하고, 시각화 정합성 문제를 해결한 최종 아키텍처를 정의합니다.

## 🏗️ 시스템 아키텍처

### 1단계: 시장 데이터 준비 (Data Preparation)
- **위치**: `backtester/backend/routes/backtest.py`
- **로직**:
    - **해상도 감지**: `resolution.lower()`를 사용하여 대소문자 구분 없이 `minute` 또는 `daily` 경로 설정.
    - **데이터 수집**: 시작일 기준 **30일 이전 데이터**부터 수집하여 지표 웜업(Warm-up) 보장.
    - **포맷팅**: 분봉 데이터는 `YYYYMMDD HH:mm:ss` 형식으로 저장 (`DataConverter.py`).
    - **무결성 검증**: 캐시된 파일이 해상도에 맞는 올바른 포맷(시간 정보 포함 여부)을 가지고 있는지 체크하여 오염된 데이터 자동 감지/삭제.

### 2단계: 알고리즘 코드 생성 (Code Generation)
- **위치**: `backtester/kis_backtest/codegen/generator.py`
- **로직**:
    - **컨텍스트 동기화**: `generate()` 호출 시 `self.resolution`을 저장하여 데이터 클래스 생성 시 참조.
    - **데이터 인프라**: `KRXEquity` 클래스가 해상도에 맞는 폴더(`minute/` 또는 `daily/`)를 참조하고 정확한 `strptime` 포맷을 사용하도록 동적 생성.
    - **커스텀 플로팅**: 엔진 기본 차트와의 충돌을 피하기 위해 `MinuteValue`라는 독립 차트에 매 분 자산 가치를 기록.

### 3단계: 결과 처리 및 샘플링 (Post-Processing)
- **위치**: `backtester/backend/routes/backtest.py`
- **로직**:
    - **데이터 소스 선택**: `MinuteValue` 차트가 존재할 경우 이를 우선적으로 자산 곡선 데이터로 채택.
    - **샘플링**: 대용량 분봉 데이터(수만 개)로 인한 브라우저 렉 방지를 위해 최대 **2,000개** 포인트로 균등 샘플링 적용.

### 4단계: 프론트엔드 데이터 조인 (Frontend Interaction)
- **위치**: `backtester/frontend/src/app/backtest/page.tsx`
- **로직**:
    - **해상도 정합**: 분 단위 자산 타임스탬프에서 날짜 부분만 추출하여 일 단위 벤치마크(KOSPI) 데이터와 조인.
    - **시각화**: Recharts 위에서 전략 자산(Minute)과 지수(Daily)가 동일 타임라인 상에 표시되도록 정렬.

## 🚦 주요 해결 과제 (History)

1.  **해상도 불충분**: 기본 Lean 결과가 일봉인 문제를 `self.Plot`을 통한 매 분 기록으로 해결.
2.  **데이터 누락**: 수집 시 대소문자 구분 버그(`Minute` vs `minute`)로 인한 경로 이탈 해결.
3.  **지수 실종**: 타임스탬프 불일치로 인한 벤치마크 조인 오류 해결.
4.  **거래 0건**: 대형주(삼성전자)의 변동성 부족 및 대소문자 버그로 인한 데이터 공급 중단 해결.
